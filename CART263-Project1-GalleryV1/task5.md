# Task 5 - Project 1 Response

## Philippe Beauchemin — *Aquarium*
One of the most compelling aspects of this project is the dynamic movement. I especially appreciate the repulsion method used when the mouse movement stops. The fish quickly shift direction and disperse to fill the screen all while avoiding overlapping one another. The repulsion strength is also managed by “diff.setMag(1/d)” this creates a stronger repulsion for fish that are close to one another and weaker repulsion for fish that are further from one another. I think this type of movement is very effective as it mirrors how minnows dart around in a pond. I also like the contrast of the randomized colored fish on the blue background. However, in this case I would have limited the color range to exclude blue values and make sure blue fish are not generated. Alternatively, I would have just generated fish on the blue spectrum to make it seem as if you are looking at them through the water and create an illusion of depth. Noticing the impact of this coloring in this project reminds me that many times when we are coding with convoluted equations or randomizing functions we can’t fully visualize and anticipate the result. Given this nature of experimentation, I find it extremely pertinent that we remember to shift to different mindsets when finalizing a project. We should take breaks, then come back to our project and look at it through a visual artist lens, interactive lens, new user lens. When we are stuck in a code mindset we limit our project and it remains unrefined. I believe this project suffers from this nuanced consideration however overall I’m very impressed by the complex vectorized movement system. 

## Noureddine Mazzene - *Super Real Game*
This project is a great example of taking a simple idea and simple code but creating a very effective result. The way the program is structured is that when you hover over the start button it automatically changes to a random position. In this case you are only able to click the button if it randomly moves to a new location that overlaps with the mouse. The layering of these two event listeners is a very creative way to create a type of easter egg. This project also uses good data management by using a json file to store the message text array. It also uses very clean and condensed coding, one example being “attempts++”. One thing I would’ve changed however is the fact that the start button can move over center text. I would have created a boundary bounding box to prevent this from happening. Alternatively I would have made the start button background black instead of transparent in the css so that it would look like a sticker being slapped on top and then peeled off and moved around.
